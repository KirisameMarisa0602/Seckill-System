# V8.0 前后端联调与全链路业务闭环测试报告
**(内网穿透 + 支付宝沙箱 + 前后端状态机视觉联调 最终收官版)**

## 序言与测试背景
在 V1.0 至 V7.0 的迭代中，我们深度构建了高并发秒杀架构的后端底座（Redis Lua 防超卖、RabbitMQ 削峰、令牌桶限流、动态路由防刷及死信自愈）。然而，一个优秀的电商系统不能仅停留在接口层面。

本 V8.0 版本的核心目标为：**打破前后端次元壁，实现全链路的视觉与状态流转闭环**。
本次压轴测试涵盖了：前端商品状态机渲染、B端运营大盘动态交互、验证码抢购业务流转、Cpolar 隧道内网穿透，以及接入支付宝沙箱完成最终的异步回调支付闭环。所有前后端联动均已严格落库取证，标志着本系统全面达到生产级体验标准！

## 1. 基础账户体系 UI 联调与底层鉴权响应

### 1.1 C端用户：前端注册交互与双重加密落库
*   **前端注册阻断与流转**：前端页面严格限定输入格式，响应后端的校验器。

*   **数据库加盐落库核实**：注册成功后，底层精准执行明文密码加盐（Salt）及二次 MD5 加密，确保数据脱库后的绝对安全。
    ![注册信息落库，密码加盐](assets/v8.0-frontend-integration/注册信息落库，密码加盐.png)

*   **超级管理员专属通道登录**：前台设置了隐蔽的管理员入口，验证其独有的权限身份（数据库底层管理员密码以密文初始化处理）。

## 3. C端商品大盘与核心抢购 UI 状态机验证

将后端复杂的时间判断逻辑封装，交给前端进行不同阶段的精准视觉呈现。

### 3.1 首页陈列与视觉初始化
*   C端用户进入商城后，页面响应后端拉取的全量缓存信息，商品按各自独立的库存与秒杀专享价整齐陈列。
    ![商品展示主界面](assets/v8.0-frontend-integration/商品展示主界面.png)

### 3.2 动态时钟与抢购状态机
前端依据后端返回的起始时间戳与当前服务器时间，精确切换展示形态，杜绝前端强改时间骗刷：
*   **未开始状态**：按钮彻底置灰锁死，展示开抢倒计时。
    ![未开始的抢购](assets/v8.0-frontend-integration/未开始的抢购.png)
*   **抢购进行中**：时间一到，前端状态机拨红按钮并放出算术图形验证码。
    ![在时间内的抢购](assets/v8.0-frontend-integration/在时间内的抢购.png)
*   **活动已结束**：库存告罄或时间超限，立刻拉起遮罩彻底阻断通道。
    ![已结束的抢购](assets/v8.0-frontend-integration/已结束的抢购.png)

### 3.3 携图形验证码完成防刷发车
*   **抢购成功拦截与派发**：输入正确的图文算术结果验证，前端拿到动态 UUID 真实路径向后端发起冲击。排队及底层落库成功后，前端弹窗提示。
    ![抢购成功测试](assets/v8.0-frontend-integration/抢购成功测试.png)

## 4. 绝对高光环节：沙箱收银台与 Cpolar 外网穿透全闭环

脱离单机内卷，打通公网与第三方支付核心链路，让系统具备真正投产的收银能力。

### 4.1 环境架设与隧道配置
*   **沙箱网关准备**：在沙箱控制台中提取供程序调试的商家及买家充值公测账号。
    ![支付宝沙箱工具的卖家买家信息](assets/v8.0-frontend-integration/支付宝沙箱工具的卖家买家信息.png)
*   **Cpolar 隧道搭建**：由于沙箱在外网，通过建立长效 TCP/HTTP 映射，把本地 8080 端口一剑通天穿透到外网，解决异步回调通信盲区。
    ![使用cpolar内网穿透工具](assets/v8.0-frontend-integration/使用cpolar内网穿透工具处理支付宝沙箱环境.png)
*   **YML 配置精准校对**：后端 `AlipayConfig` 精密装载 Cpolar 刚刚分配的动态外网 URL，以及前端路由的回跳页面地址。
    ![yml文件中正确设置信息](assets/v8.0-frontend-integration/yml文件中正确设置沙箱异步回调通知和支付成功的返回界面（前端对应的路由）.png)

### 4.2 API 调起与实盘支付演示
*   **前台拉起支付宝当面付收银**：系统打包请求参数给支付宝，返回的 Form 表单在前端成功渲染出扫码收银台。
    ![沙箱支付测试](assets/v8.0-frontend-integration/沙箱支付测试.png)
*   **客户付款完成**：使用沙箱支付宝 APP 扫描二维码，扣款成功并出示官方成功页面。
    ![沙箱支付成功](assets/v8.0-frontend-integration/沙箱支付成功.png)

### 4.3 外网回调击穿与交易终态同步 (架构大闭环)
*   **前端视觉跳转完成**：同步返回请求成功打给前端路由，进入完美的成功清算提示页。
    ![支付成功结算页面](assets/v8.0-frontend-integration/支付成功结算页面.png)
    ![付款成功截图](assets/v8.0-frontend-integration/付款成功截图.png)
*   **底层异步状态更新核暴完成**：依靠 Cpolar 传回外网异步请求，触发系统 RSA2 验签。验签通过后，订单状态机精准流转为【状态1：已支付】，并记录了真实的打款时间戳 `pay_date`。
    ![付款成功的订单状态入库](assets/v8.0-frontend-integration/付款成功的订单状态和支付时间成功落库.png)
