#  企业级高并发秒杀系统 (Seckill-System)

##  项目简介
企业级高并发秒杀/抢票系统。基于 SpringBoot + Redis + RabbitMQ 构建，旨在解决高并发场景下的超卖、缓存穿透、分布式限流以及流量削峰等核心问题。秉承规范的分层架构思想，为应对超频并发请求提供高可用解决方案。

##  核心技术栈
- **后端框架**: Spring Boot 2.7, MyBatis-Plus
- **数据库**: MySQL 8.0 (唯一索引防重机制)
- **分布式缓存**: Redis + Redisson (布隆过滤器 + 分布式锁)
- **本地缓存**: Guava Cache (应对极热点数据)
- **消息队列**: RabbitMQ (异步下单削峰、死信队列处理超时订单)
- **测试与压测**: JMeter, JUnit
